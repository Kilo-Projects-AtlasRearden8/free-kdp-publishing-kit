# Pre-Launch Checklist

Use this list before your book goes live on Amazon Kindle Direct Publishing (KDP).
Print it, check each box by hand, and don't skip the proof copy — it's the best
way to catch mistakes before readers see them.

Credit: Asdale Dynamics, LLC. More plain-English publishing help at
dylanasdale.github.io

## 1. Manuscript is ready

- [ ] Manuscript is finished and edited (spelling, grammar, formatting)
- [ ] Chapter headings use real heading styles (Heading 1, Heading 2), not just bold text
- [ ] Table of contents works and page numbers/links are correct
- [ ] Front matter is in place: title page, copyright page, disclaimer if needed
- [ ] Back matter is in place: author bio, other books by you, request for a review
- [ ] File saved as DOCX or EPUB (KDP accepts both)

## 2. Cover is ready

- [ ] Cover file is print-ready PDF (paperback) or JPG/TIFF (ebook), per KDP specs
- [ ] Cover dimensions match your trim size and page count
- [ ] Spine text is readable and centered
- [ ] Back cover has a blurb, barcode area, and ISBN placeholder if needed
- [ ] You've viewed the cover at thumbnail size — title is still readable

## 3. KDP account and book details

- [ ] KDP account is created at kdp.amazon.com and identity/tax info is complete
- [ ] Book title and subtitle are final
- [ ] Author name is exactly how you want it to appear
- [ ] Book description is written (hook, summary, author bio)
- [ ] Two Amazon categories are chosen
- [ ] Seven keywords or keyword phrases are chosen
- [ ] Content type and language are selected
- [ ] ISBN decided: free KDP ISBN or your own purchased ISBN

## 4. Pricing and rights

- [ ] Royalty option chosen (35% or 70% for ebooks; 60% for paperbacks)
- [ ] List price set for each marketplace you'll sell in
- [ ] Territories set (all territories or specific countries)
- [ ] Lending and matching options set (ebooks)
- [ ] Pre-order set up, if you want one (optional)

## 5. Proof and approval

- [ ] Digital previewer checked: no weird line breaks, images render, TOC works
- [ ] Print proof copy ordered and received (strongly recommended for paperbacks)
- [ ] Proof reviewed page by page for typos, layout, and color issues
- [ ] Any changes made in your manuscript/cover files and re-uploaded

## 6. Launch week prep

- [ ] Launch date picked
- [ ] Launch-week calendar filled out (see launch-week-calendar)
- [ ] Email list or social media posts drafted and scheduled
- [ * ] Author Central profile set up at authorcentral.amazon.com
- [ * ] Plan in place for asking readers for honest reviews after launch

\* Optional but recommended.
