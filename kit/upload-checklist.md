# KDP Upload Checklist

Step by step, from signing in to hitting Publish. Check each box as you go.

Credit: Asdale Dynamics, LLC. More plain-English publishing help at
dylanasdale.github.io

## Before you start

- [ ] KDP account is active at kdp.amazon.com
- [ ] Tax and bank information are complete in your account
- [ ] Manuscript file ready (DOCX or EPUB)
- [ ] Cover file ready (PDF for print, JPG/TIFF for ebook)
- [ ] Metadata worksheet filled out (title, description, categories, keywords)

## Create the title

- [ ] Click "Create" → "Paperback" (or "Kindle ebook" / "Hardcover")
- [ ] Enter language
- [ ] Enter book title and subtitle exactly as finalized
- [ ] Enter author name and any contributors
- [ ] Enter book description (hook + synopsis + author bio)
- [ ] Confirm publishing rights (you own it or have permission)

## Content upload

- [ ] Upload manuscript file
- [ ] Wait for upload and conversion to finish
- [ ] Use the digital previewer to check every page
- [ ] Fix any formatting or line-break issues, then re-upload
- [ ] Upload cover file
- [ ] Use the cover previewer to check front, spine, and back
- [ ] Order a printed proof copy for paperbacks (recommended)

## Details

- [ ] Enter your two (up to three) categories
- [ ] Enter up to seven keywords
- [ ] Enter ISBN (or select free KDP ISBN)
- [ ] Set content type and language again if not carried over

## Pricing

- [ ] Choose royalty option (35% or 70% for ebooks)
- [ ] Set list price for each marketplace
- [ ] Confirm minimum price shown by KDP is met
- [ ] Set territories (all territories recommended for most authors)
- [ ] Set lending and paperback match options if applicable

## Publish

- [ ] Click "Publish" (ebook) or "Publish your paperback book"
- [ ] Wait for the book to appear in the Kindle Store (usually 24–72 hours)
- [ ] Order another proof if you made changes after the first one
- [ ] Claim your book on Author Central (authorcentral.amazon.com)
- [ ] Add the book to your series page, if applicable
- [ ] Share your Amazon book link with your email list and social media

## After launch

- [ ] Check sales dashboard in KDP after 7 days
- [ ] Read any reviews and note reader feedback
- [ ] Adjust price, categories, or keywords if needed (KDP lets you edit these)
- [ ] Celebrate — you published a book!
